คู่มือติดตั้ง FortiClient บน iPhone / iPad

FortiClient > FortiToken > THP VPN

ก่อนเริ่ม: เตรียม Internet, Invitation Code และ Username / Password

ส่วนที่ 1 - ติดตั้ง FortiClient

  1. ดาวน์โหลด FortiClient

    ดาวน์โหลดจาก App Store แล้วเปิดแอป

  2. เลือก Invitation Code

    กด Connect แล้วเลือก Invitation Code

  3. กรอก Invitation Code และเข้าสู่ระบบ

    กรอก Invitation Code แล้วกด OK จากนั้นกรอก Username / Password และกด Login

ส่วนที่ 2 - ตั้งค่า FortiToken

  1. FortiToken Mobile

    ดาวน์โหลดแอป FortiToken Mobile

  2. ลงทะเบียน Token

    เลือก Scan Barcode หรือ Enter Manually จากอีเมล FTM Activation on FortiGate

    ห้ามแชร์ QR Code หรือ Key: ข้อมูลนี้ใช้ลงทะเบียนเฉพาะบุคคล

  3. ดู Token

    กดรูปตาเพื่อดูเลข Token 6 หลัก

ส่วนที่ 3 - เชื่อมต่อ THP VPN

  1. เลือก VPN และกรอก Username / Password

    เลือก VPN > THP_VPN > Connect แล้วกรอก Username / Password

  2. ยืนยัน Token

    วิธีที่ 2: กด Approve ใน FortiToken

  3. ตรวจสอบ Connected

    สถานะต้องเป็น Connected
